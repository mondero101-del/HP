Particles HP, flat version (no folders)

1. Upload every file EXCEPT build-apk.yml to your GitHub repository with Add file > Upload files.
2. On GitHub choose Add file > Create new file. In the name box type exactly:
   .github/workflows/build-apk.yml
   Open build-apk.yml from this folder in a text viewer, copy all of it, paste it into the big box, then Commit changes.
3. Open the Actions tab and wait for the green tick (5 to 8 minutes).
4. Download Particles-HP.apk from Releases.
